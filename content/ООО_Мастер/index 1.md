# Папка daily
daily - ежедневные заметки, она включает заметки на бумаге (тег #a4, или иной которые записаны, но пока не отнесены к какой либо теме или проекту). Кроме того требуется добавить в Quartz модуль календарь, как в Obsidian, чтобы слева показывал даты и точки которые отображают наличие и размер заметок в папке daily так же как сейчас справа есть последние заметки.

```dataview
TABLE WITHOUT ID file.link AS "Заметка",
dateformat(file.mtime, "dd.MM.yyyy - HH:mm") AS "Последнее посещение"
FROM "Педагогика" // из Папки Педагогика
WHERE file.mtime >= date(today) - dur(7 days)  // За последние 7 дней
SORT file.mtime DESC
LIMIT 20 // последние 20 заметок
```
