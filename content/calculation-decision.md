## Решение 1. #archive
Объектный подход — создать серию шаблонов (типовых КП) по объектам с изменяемой частью (то что выбрано покупателем). 
Сложности: Для каждого вида лоджии требуется реструктуризация имеющихся данных по отделке и теплому полу. (Изменение структуры прайса)
Достоинства: Наглядность для покупателя.

Задачи:
- [ ] Переработать прайс по отделке, реализуя объектный подход.
- [ ] Подобрать изображения объектов
- [ ] Разработать печатную продукцию для замерщика.
- [ ] Рисунок при помощи фигур, подставляется только окно.
## Решение 2. 
Сделать калькулятор на основе существующей структуры, только для быстрого расчёта используя 4 функции: 
Двссыл, смещ, ВПР и проверку данных.

Для удобства можно цветом промаркировать операции: остекление, утепление, отделка, электрика и тд и соответственные области в КП назначить.
