# Смена кодировки

Поменять кодировку файла с Windows CP-1251 на UTF-8 посредством консоли

Утилита **enconv** в составе пакета **enca**

1. узнать, в какой кодировке файл:
`file -i file.txt`
`enca file.txt`

2. Узнав исходную кодировку файла, меняем её с помощью команды:  
  
`iconv -f cp1251 -t utf8 file.txt -o newfile.txt`

3. Программа сама определит кодировку файла, и преобразует её к кодировке текущей локали:
  
`enconv file.txt`

# Символическая ссылка

- Может ссылаться на файл и каталог.
- После удаления, перемещения или переименования файла  становится недействительной.
- Имеет собственные права доступа и [[номер inode]]. 
- При изменении прав доступа к целевому файлу права ссылки не меняются.
- Можно ссылаться на другие разделы диска.
- Содержат только имя файла или каталога, а не его содержимое.

# Работа с pdf
Иногда требуется разделить многостраничный pdf файл и сохранить как два разных документа. В linux для этого есть утилита `pdftk`

Для начала установим саму утилиту `pdftk`:

```
$ sudo apt-get install pdftk
```

Итак, к примеру, чтобы извлечь 5-ю страницу из файла `ORIG_FILE.pdf`  и сохранить её в `NEW_FILE.pdf` нужно:

```
$ pdftk ORIG_FILE.pdf cat 5 output NEW_FILE.pdf
```

Чтобы извлечь несколько страниц в один файл:

```
$ pdftk ORIG_FILE.pdf cat 1 4 6 output NEW_FILE.pdf
```

Извлекаем диапозон страниц:

```
$ pdftk ORIG_FILE.pdf cat 1-5 output NEW_FILE.pdf
```

Так же можно совместить два последниз способа: 

```
$ pdftk ORIG_FILE.pdf cat 1 5 7 10-12 output NEW_FILE.pdf
```
